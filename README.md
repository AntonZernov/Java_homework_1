# Домашнее задание 1
## Консольное приложение Студенты

Выбор пунктов меню осуществляется с помощью ввода цифр.
Приложение работает в цикле до выбора пункта выход.

## Формат данных
Текстовый файл csv по одному студенту на строку.
Строка состоит из ФИО, среднего балла и номера зачетки.
Значения разделены ";" (точка с запятой).

## Валидация 
Имя допускает только буквы и пробелы.
Средний балл от 2 до 5. Допускается дробное значение с разделителем
разрядов как в виде точки так и запятой.
Номер зачетки - только цифры. Проверяется уникальность.
При ручном вводе приложение циклично требует ввода корректного номера зачетки,
При чтении из файла - пропускает некорректные строки.

Путь к файлу относительный. Пример в корне проекта.
Для чтения из этого файла достаточно ввести путь "students.csv".
